# Конфиденциальность и данные

## Какие данные обрабатываются

### Аудио

Во время диктовки звук хранится в оперативной памяти как mono PCM. Он
отправляется в OpenAI для распознавания и не сохраняется приложением на диск.
При полном сбое аудио остаётся в памяти до повтора, отмены или закрытия
программы.

### Текст

Распознанный текст:

- помещается в буфер обмена Windows;
- при включённой постобработке отправляется в DeepSeek;
- сохраняется в локальной истории из последних 50 результатов.

Буфер обмена является общесистемным ресурсом: другие программы с доступом к
нему потенциально могут прочитать его содержимое.

### API-ключи

Ключи хранятся в Windows Credential Manager под именами:

- `SpeechToText/OpenAI`;
- `SpeechToText/DeepSeek`.

Они не записываются в `settings.json`, исходный код, ZIP или технические логи.

### Настройки и история

Файлы находятся в `%LOCALAPPDATA%\SpeechToText`:

- `settings.json` — режим, микрофон, горячие клавиши и пользовательский словарь;
- `history.bin` — история, защищённая Windows DPAPI для текущего пользователя.

Пользовательский словарь не шифруется, поэтому не следует хранить в нём пароли,
API-ключи или иные секреты.

## Внешние сервисы

Приложение подключается напрямую к:

- `api.openai.com` — аудио, язык и словарь для распознавания;
- `api.deepseek.com` — транскрипт и словарь для постобработки, если она включена.

Дальнейшая обработка этих данных регулируется условиями и политиками
соответствующего провайдера. Собственного промежуточного сервера у проекта нет.

## Что приложение не делает

- не записывает аудиофайлы;
- не создаёт логи с текстами или ключами;
- не отправляет телеметрию разработчику;
- не начинает запись и не проверяет API при автозапуске;
- не вставляет текст в другое окно, если исходное окно перестало быть активным.

## Как удалить локальные данные

1. Очистите историю в настройках.
2. Удалите содержимое полей API-ключей и сохраните настройки.
3. Выключите автозапуск.
4. Завершите приложение.
5. Удалите папку `%LOCALAPPDATA%\SpeechToText`.

После этого portable-папку программы можно удалить обычным способом.
