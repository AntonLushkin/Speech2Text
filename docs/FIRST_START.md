# Первый запуск

## Перед началом

Потребуются:

- Windows 10 x64 и .NET Framework 4.8;
- рабочий микрофон;
- интернет;
- собственный API-ключ OpenAI;
- при необходимости — собственный ключ DeepSeek.

Программа не содержит общих или демонстрационных API-ключей. Запросы
оплачиваются владельцем ключа напрямую по тарифам выбранного сервиса.

## Установка

1. Скачайте `pis.etc-win10-x64-v1.1.1.zip` из раздела Releases.
2. Сверьте SHA-256 архива со значением, опубликованным в описании релиза.
3. Полностью распакуйте архив в постоянную папку. Не запускайте программу прямо
   из ZIP.
4. Откройте `SpeechToText.exe`.

Портфолио-сборка пока не имеет цифровой подписи издателя. Поэтому SmartScreen
может показать предупреждение. Продолжайте запуск только если архив скачан со
страницы Releases этого репозитория и его контрольная сумма совпала.

## Настройка

1. На вкладке «API-ключи» вставьте ключ OpenAI.
2. Если нужна очистка и пунктуация через DeepSeek, добавьте его ключ и включите
   обработку.
3. В «Общих» выберите микрофон и запустите трёхсекундную проверку.
4. Оставьте экономичный режим для минимальной стоимости либо выберите быстрый
   режим для потоковой передачи звука.
5. При желании включите «Запускать вместе с Windows».
6. Нажмите «Сохранить».

Основное управление:

- удерживать `Левый Ctrl + Левый Alt` — говорить;
- отпустить любую из клавиш — закончить и вставить текст;
- `Левый Ctrl + Пробел` — сменить режим;
- `Esc` — отменить запись.

Если после диктовки исходное окно перестало быть активным, текст намеренно не
будет вставлен в другое приложение. Он останется в буфере обмена и зашифрованной
истории.

## Где хранятся данные

- настройки: `%LOCALAPPDATA%\SpeechToText\settings.json`;
- история: `%LOCALAPPDATA%\SpeechToText\history.bin`, защищена DPAPI;
- ключи: Диспетчер учётных данных Windows;
- аудио: только оперативная память.

Подробнее: [`PRIVACY.md`](PRIVACY.md).

## Сеть и VPN

OpenAI API должен быть доступен из сети пользователя. При использовании VPN с
раздельным туннелированием добавьте `SpeechToText.exe` в список приложений,
которые работают через VPN. После замены или переноса программы убедитесь, что
правило по-прежнему относится к запускаемому экземпляру. Обычный HTTPS и
Realtime WebSocket должны проходить через один и тот же разрешённый маршрут.
