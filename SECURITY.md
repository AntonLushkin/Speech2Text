# Политика безопасности

## Поддерживаемая версия

Сейчас поддерживается версия `1.1.x`.

## Как сообщить об уязвимости

Если в репозитории включена функция private vulnerability reporting, используйте
**Security → Advisories → Report a vulnerability**. Это предпочтительный способ
для сведений, которые нельзя публиковать до исправления.

Для обычной ошибки можно создать GitHub Issue, но сначала удалите из текста и
скриншотов:

- API-ключи и заголовки `Authorization`;
- содержимое Диспетчера учётных данных Windows;
- надиктованный текст и историю;
- имена пользователей и локальные пути;
- сведения, по которым можно определить аккаунт OpenAI или DeepSeek.

Никогда не прикладывайте папку `%LOCALAPPDATA%\SpeechToText` целиком.

## Если ключ случайно опубликован

Удаления строки из последнего коммита недостаточно: значение может остаться в
истории Git. Немедленно отзовите ключ в кабинете провайдера, создайте новый, а
затем очистите историю репозитория.
