# Сторонние компоненты

`pis.etc` использует сторонние библиотеки, права на которые принадлежат их
авторам.

## NAudio 2.2.1

- Назначение: захват и обработка звука в Windows.
- Проект: <https://github.com/naudio/NAudio>
- Лицензия: MIT.
- Copyright: Mark Heath и участники проекта NAudio.

## Библиотеки .NET

Готовый portable-пакет может содержать распространяемые вместе с
NuGet-зависимостями сборки:

- `Microsoft.Win32.Registry`;
- `System.Security.AccessControl`;
- `System.Security.Principal.Windows`.

Они относятся к проекту .NET:

- Проект: <https://github.com/dotnet/runtime>
- Лицензия: MIT.
- Copyright: .NET Foundation и участники проекта.

Этот файл не изменяет условия лицензирования перечисленных компонентов.
